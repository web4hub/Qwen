# QwenCloud Docs

> QwenCloud provides API access to Qwen large language models and multimodal AI. Capabilities include text generation, vision, image generation, video generation, speech-to-text, text-to-speech, speech-to-speech, embeddings, and reranking via OpenAI-compatible, Anthropic-compatible, and DashScope endpoints.

## Token Plan

- [Token Plan](https://docs.qwencloud.com/token-plan/overview.md): Token Plan is an AI model subscription service from QwenCloud, using Credits as a unified billing unit across text, image, and video generation models. Available in Personal Edition and Team Edition.
